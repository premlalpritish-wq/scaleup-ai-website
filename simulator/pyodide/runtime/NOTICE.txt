Pyodide runtime 314.0.7
======================

This directory contains the Pyodide 314.0.7 browser runtime and its Python
standard-library archive, distributed under the Mozilla Public License 2.0.
See LICENSE.txt and https://github.com/pyodide/pyodide for the corresponding
source. The runtime is pinned and loaded from the same origin as this demo.

The files in ../model/ and ../runner/ are ScaleUp AI copies of the named
Ganjave Python model modules and composition worker. They are checked byte for
byte against their source paths by web/tests/pyodide_parity.mjs.
